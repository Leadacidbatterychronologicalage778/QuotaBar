安装

  1. 从 GitHub Releases 下载 `QuotaBar-v1.0.0-macOS-arm64.zip`。
  2. 解压后把 QuotaBar 拖入“应用程序”文件夹。
  3. 首次启动时按住 Control 点击 App，选择“打开”，再确认“打开”。

当前发布包采用临时签名且未经过 Apple 公证，因此首次打开需要额外确认。

开始使用

  1. 启动 QuotaBar，并通过 Codex 官方流程登录 ChatGPT。
  2. 点击菜单栏中的 QuotaBar 图标查看额度。
  3. 使用刷新按钮立即更新，或等待每 60 秒自动刷新。
